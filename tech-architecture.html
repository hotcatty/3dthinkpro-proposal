Technical Architecture · 技术决策

独立站技术架构方案

前后端分离方案的核心逻辑、成本结构、后端管理与结算方案全览，供团队决策参考。

方向确定：前后端分离 商业后台：Shopify 原型已上线 后续：后端 + 支付落地

Core Decision · 核心决策

我们选了什么，为什么

前后端分离 = 前端（网站视觉）和后端（商品/订单/支付）各自独立，互不绑定。

前端（网站界面）— 我们自己做

用 Next.js + React 构建，部署在 Vercel。网站的每一处视觉细节完全自主，不受任何主题模板约束。目前原型已完成，还原度高，后续修改极快。

后端（商业系统）— Shopify 托管

Shopify 负责商品上架、库存、订单处理、支付收款、物流对接。这部分全走 Shopify 管理后台，无需写任何代码，和传统开 Shopify 店没有区别。

与传统 Shopify 主题方案的关键区别：只有"网站长什么样"是我们自己控制的，其余的商业运营能力（商品管理、结账、物流、数据）全部还是 Shopify 在跑。两全其美——设计自由 + 成熟商业系统。

Checkout · 结算方案

结算页三套方案

前后端分离在结算页有一个特殊问题：默认点击购买会跳转到 Shopify 原生 Checkout 页面，与我们的界面有视觉断层。以下是三个解决路径，由易到深。

方案 A · 短期

Shopify Checkout 品牌化

CSS 覆盖样式

所有套餐均支持，1–2 小时完成

为跳转后的 Checkout 页替换品牌配色、Logo、字体，跳转感大幅降低。不改结构，改的是外观。

方案 B · 中期推荐

Stripe 嵌入式支付

完全无跳转

2.9% + $0.30 /笔，无月费，一次性开发

将支付表单直接嵌入我们自己的页面，用户全程不离开。Shopify 继续管商品和订单，Stripe 管安全收款，前端样式 100% 由我们控制。

注：Stripe 是独立支付公司，Shopify Payments 底层即是 Stripe，费率完全相同。

方案 C · 远期

Shopify Plus

$2,000 /月

适合规模化后的升级方向

开放 Checkout 完整自定义权限，可彻底重写结算页前端。当前阶段性价比不足，作为远期方向保留。

后续调研项：Stripe 嵌入方案（方案 B）是兼顾体验和成本的最优路径，需进一步调研 Stripe 在目标市场（北美、欧洲）的合规要求，以及与 Shopify 订单系统的对接流程，作为下阶段落地任务。

Backend · 后端管理

Shopify 是当前最合适的后端选择

我们对后端的核心需求：商品管理、订单管理、安全收款。Shopify 在这三点上提供了市场上最成熟、国际信任度最高的现成方案。

Shopify 商品管理

  • 多规格 SKU（车型 × 年份 × 颜色）
  • 库存实时同步
  • 批量上下架、定时发布
  • 多图、视频、3D 模型支持
  • 多币种、多语言商品信息

Shopify 订单与物流

  • 订单全生命周期管理
  • 自动发送订单确认邮件
  • 物流商接入（DHL、FedEx、EasyPost）
  • 自动运费计算、退货流程
  • 数据仪表盘（销售额、转化率、客单价）

后续落地任务

当前原型网站已完成前端视觉，下一阶段的核心工作是将 Shopify 后端真正接入：连通商品数据、配置 Shopify Payments、设置运费规则，并完成结算方案的技术选型和实施（Stripe 嵌入方案为优先方向）。

这部分需要一定时间进行调研和开发落地，建议作为下阶段并行推进的重点。
